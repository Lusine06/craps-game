# Craps Game

## About the Project

This project is a Python implementation of the classic Craps dice game.

The player rolls two dice, and the program calculates the sum of the two dice. 
The result of the first roll determines whether the player wins immediately, 
loses immediately, or gets a goal number that they need to roll again.

## Game Rules

The rules of the game are:

- If the first roll is **7 or 11**, the player wins.
- If the first roll is **2, 3, or 12**, the casino wins.
- If the first roll is **4, 5, 6, 8, 9, or 10**, that number becomes the goal number.
- The player continues rolling the dice until they roll the goal number or a 7.
- If the player rolls the goal number first, the player wins.
- If the player rolls a 7 before the goal number, the casino wins.
